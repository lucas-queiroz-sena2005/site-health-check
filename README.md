# Site Health Check Prototype

This package contains the interactive frontend prototype for the Site Health Check dashboard.

## Requirements
- Docker
- Docker Compose

## How to Run

1. Open a terminal in this directory.
2. Run the following command to build and start the prototype:
   ```bash
   docker compose up --build -d
   ```
3. Open your web browser and navigate to: **http://localhost:8080**

## How to Stop
When you are done testing, you can stop the prototype by running:
```bash
docker compose down
```

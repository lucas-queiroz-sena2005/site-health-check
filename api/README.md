# Site Health Check - API Backend

This is the FastAPI backend for the Site Health Check project.

## Architecture & Subprocess

The API acts as a web wrapper and state manager for the underlying `engine` module. When a job is launched via `/api/jobs/launch`, the API performs the following steps:
1. Validates the incoming parameters using dynamic Pydantic schemas (`ExecutionConfig` & `ExecutionFlags`).
2. Generates a completely dynamic CLI argument list based on metadata bound to the Pydantic schemas (ex. translating `{"check_http": true}` to `--check-http`).
3. Dispatches a background task (`asyncio.create_subprocess_exec`) that executes the `engine.cli` module in a separate process.
4. Streams the stdout/stderr logs generated by the `engine` process back to the frontend in real-time via Server-Sent Events (SSE).

## Dependency Management (uv)

The repo is a [uv](https://docs.astral.sh/uv/) workspace (root `pyproject.toml`, members `api` and `engine`, single `uv.lock`). `api` depends on `engine` as a workspace member.

- To install everything natively (without Docker), from the repo root:
  ```bash
  uv sync
  ```
- To add a new package to the API:
  ```bash
  uv add --package api <package>
  ```

## Running Locally (without Docker)

```bash
uv run uvicorn api.main:app --reload --host 127.0.0.1 --port 8000
```

## Tests

```bash
uv run pytest                      # all tests
uv run pytest -m "not integration" # skip tests that spawn real processes
```

Once running, navigate to the auto-generated documentation at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) to view all endpoints, test payloads, and inspect schemas.
